# Shubham Super Shopee — React Native apps

Two React Native (Expo) companions for the Shubham Super Shopee hybrid
monorepo, rewritten from the existing web apps:

| App | Directory | Package | Replaces |
|---|---|---|---|
| **Customer storefront** | `shop-app/` | `com.shubhamsupershopee.shop` | `shop/` (web storefront) |
| **Admin ERP** | `erp-app/` | `com.shubhamsupershopee.erp` | repo root (web ERP) |

Both apps share the Fresh Cart brand system (electric lime `#c8f135`, tomato
coral `#ff5233`, mango `#ffc531`, cream `#f7f9ef`, deep pine `#07332a`;
Unbounded display + Schibsted Grotesk body).

## Feature parity highlights

**shop-app** — product grid with categories & search, Deal of the Day
(deterministic IST rotation), product detail with reviews, local cart
(AsyncStorage), coupons (`FIRST50`, `FREESHIP`, festive `DIWALI10`), checkout
(COD + UPI intent), order confirmation + order lookup, **one-click English ↔
मराठी for the whole app** (same 227-key dictionary + grocery glossary as the
web storefront, with Noto Sans Devanagari).

**erp-app** — passkey login against the live ERP (same session cookie as the
web admin), dashboard (today/month stats, 14-day income bars, low stock,
pending udhar), **POS** (sale → stock decrement + income booking), products
(add/edit), **udhar credit ledger** (add / part-payments / settle), customers,
reports (monthly comparison, expense categories, top stock).

Both apps run in two modes:
- **LIVE** — point at the deployed web app (Settings → API URL). The shop app
  drives `/api/products`, `/api/cart`, `/api/checkout`, `/api/orders`,
  `/api/translate`; the ERP app drives `/api/auth`, `/api/dashboard`,
  `/api/products`, `/api/sales`, `/api/udhar`, `/api/customers`.
- **DEMO** (default) — a bundled 16-product catalog + realistic ledgers, so
  the apps are fully explorable offline before wiring anything.

## Development

```bash
cd shop-app   # or erp-app
bun install
npx expo start --web        # browser QA (ports 4000/4001 in the sandbox)
bunx tsc --noEmit           # typecheck
```

## Release APKs

Built 2026-11-06 with the sandbox pipeline below. `scripts/patch-mirrors.sh`
is the complete post-prebuild patcher: Aliyun mirrors (Maven Central 429s),
2 physical ABIs, low-RAM Gradle profile, release signing, `ndk.abiFilters`.

```bash
cd shop-app                          # or erp-app
bun install
npx expo prebuild -p android --no-install
./scripts/patch-mirrors.sh           # mirrors + ABIs + signing + RAM profile
# place sss-<app>-release.keystore + keystore.properties in android/app/
# (gitignored — see Signing below)
cd android && ./gradlew assembleRelease -x lint
# → android/app/build/outputs/apk/release/app-release.apk
```

Requirements: JDK 21 (with `javac`), Android SDK 36 + build-tools 36.0.0 +
NDK 27.1. On low-RAM machines Gradle compiles fine with the profile the
patcher writes (`workers.max=1`, in-process Kotlin, 1GB daemon heap).

## Signing

Each app is signed with its own keystore (`com.shubhamsupershopee.shop` /
`com.shubhamsupershopee.erp`). Keystores + `keystore.properties` are
gitignored (`android/` is regenerated by prebuild) — **keep a backup to ship
updates as the same app identity**. Sandbox backup lives outside the repo
with the password scheme in the delivery notes.
